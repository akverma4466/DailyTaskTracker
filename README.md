📅 Daily Task Tracker

A simple, responsive, and user-friendly web application designed to manage daily tasks, track productivity, and monitor progress over time.

Daily Task Tracker helps users organize their tasks, maintain consistency, track completed activities, and analyze their overall productivity through progress statistics.

🚀 Features

Task Management – Add, manage, and organize daily tasks.

Task Categories – Categorize tasks for better organization.

Priority Management – Set priorities for different tasks.

Daily Progress Tracking – Mark tasks as completed or pending.

Completion History – View previously completed tasks and daily records.

Productivity Dashboard – Monitor total, completed, and pending tasks.

Progress Percentage – Calculate daily and overall completion percentages.

Consistency Tracking – Monitor productivity and task completion consistency.

Database Integration – Store and manage tasks using Supabase.

Real-Time Data Management – Fetch and update task information from the database.

⚙️ Getting Started

1. Clone the Repository

git clone https://github.com/your-username/daily-task-tracker.git

2. Open Project Folder

cd daily-task-tracker

3. Configure Supabase

Create a project on Supabase.

Set up the required database tables.

Configure your Supabase Project URL and Publishable Key in the application.

Configure appropriate Row Level Security (RLS) policies.

4. Run the Application

Open index.html using VS Code Live Server or your preferred local development server.

🔐 Security

Supabase Row Level Security (RLS).

Secure database access policies.

Never expose Supabase service role keys in frontend code.

Use only the publishable key in client-side applications with properly configured RLS.
